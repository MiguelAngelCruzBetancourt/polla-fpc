# Prompt para rediseñar el flujo de navegación y gestión de salas

Quiero que actúes como un **Senior UI/UX Designer** y **Senior Frontend Architect**.

## Cambios solicitados

### Ranking
- Convertir el ranking en una lista vertical.
- Destacar el primer lugar con color dorado y el segundo con color plateado.
- Opcionalmente destacar el tercero con bronce.

### Salir de una sala
- Agregar un botón funcional para salir de la sala.
- Mostrar un cuadro de confirmación antes de abandonar la sala.

### Nuevo flujo
- Si el usuario no pertenece a ninguna sala, mostrar únicamente **Crear sala** y **Unirse a sala**.
- Cuando pertenezca a una o más salas, mostrar un selector desplegable de salas en la parte superior.
- Al cambiar de sala, actualizar automáticamente toda la información.

### Nuevo navbar inferior
- Historial
- Calendario
- Ranking
- Miembros
- Configuración

### Configuración
- Salir de la sala.
- Crear una nueva sala.
- Unirse a otra sala.

### Diseño
Mantener un diseño moderno, minimalista, accesible, con tonos neutros y la regla 60-30-10.

### Arquitectura
Indicar componentes nuevos, reutilizables, estados globales y cambios necesarios para soportar este flujo.

## Resultado esperado
Entregar una propuesta completa de UX, UI y arquitectura con justificación de todas las decisiones.
