# Prompt para mejorar la interfaz de una aplicación

Quiero que actúes como un **UI/UX Designer Senior** especializado en diseño de aplicaciones modernas, minimalistas y accesibles. Tu objetivo es rediseñar completamente la interfaz de mi aplicación para que tenga una apariencia profesional, limpia y agradable para cualquier tipo de usuario.

## Objetivos

Analiza toda la aplicación y propón mejoras en:

- Diseño visual.
- Distribución de los elementos.
- Espaciados.
- Tipografía.
- Iconografía.
- Colores.
- Componentes.
- Navegación.
- Accesibilidad.
- Responsive Design (si aplica).

No quiero únicamente recomendaciones; quiero que indiques exactamente qué cambiar, por qué cambiarlo y cómo implementarlo.

## Estilo visual

La aplicación debe transmitir elegancia, modernidad, minimalismo, profesionalismo y claridad.

Inspírate en Material 3, Apple Human Interface y Fluent Design, manteniendo una identidad propia.

## Paleta de colores

Utiliza tonos neutros y minimalistas aplicando la regla **60-30-10**:

- 60% fondo principal.
- 30% superficies, tarjetas y paneles.
- 10% color de acento para botones y elementos importantes.

Evita colores saturados y prioriza una interfaz agradable para largas sesiones.

## Accesibilidad

- Excelente contraste.
- Tipografía legible.
- Componentes fáciles de identificar.
- Navegación intuitiva.
- Diseño amigable para usuarios de todas las edades.

## Componentes

Rediseña botones, tablas, formularios, tarjetas, modales, barras laterales, menús, barra superior, inputs, selects, calendarios, alertas, badges y tooltips con un estilo consistente.

## Iconografía

Recomienda una librería moderna y explica por qué.

## Logos e imágenes

La aplicación está relacionada con la **Liga BetPlay**.

Indícame exactamente:

- Qué logos debo descargar.
- Qué escudos de equipos necesito.
- Qué imágenes son recomendables.
- Qué iconos debo conseguir.
- Qué formato usar (SVG preferiblemente).
- En qué carpeta del proyecto debe ir cada recurso.

Sugiere una estructura como:

```text
assets/
├── logos/
├── teams/
├── icons/
├── backgrounds/
└── illustrations/
```

Para cada recurso indica:

- Nombre del archivo.
- Carpeta destino.
- Uso dentro de la interfaz.

## Tipografía

Recomienda fuentes como Inter, Poppins, Manrope o Roboto indicando cuál usar para títulos, subtítulos, texto y botones.

## UX

La aplicación debe sentirse fluida, intuitiva, ordenada, moderna y profesional.

## Animaciones

Sugiere animaciones suaves para hover, botones, tarjetas, cambios de pantalla, carga de datos y modales.

## Resultado esperado

Entrega:

1. Diagnóstico del diseño actual.
2. Problemas encontrados.
3. Mejoras propuestas.
4. Nueva paleta de colores.
5. Tipografías.
6. Iconografía.
7. Componentes.
8. Distribución de pantallas.
9. Organización de recursos gráficos.
10. Lista completa de logos, imágenes e iconos necesarios.
11. Recomendaciones de implementación.
12. Justificación de todas las decisiones de diseño.

El objetivo es obtener una aplicación moderna, minimalista, accesible y visualmente atractiva inspirada en las mejores prácticas de UI/UX para una aplicación relacionada con la Liga BetPlay.
